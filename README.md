# Introduction to Computation and Programming Using Python

Personal exercises, solutions, and implementations based on *Introduction to Computation and Programming Using Python* (3rd Edition), by **John V. Guttag**.

## About

This repository documents my progress through the book as part of my self-directed Computer Science studies.

The goal is to develop a solid understanding of computational thinking, problem-solving, algorithms, and programming with Python.

## Repository Structure

The repository will be organized by chapter, containing my solutions to exercises, experiments, and implementations.

## Progress

**Status:** In progress.

### Chapter 2 — Finger Exercises

- `finger_exercise01.py`: **Finding the largest odd number among three integers.** — Reads three integers and prints the largest odd number entered; if none are odd, prints the smallest number.
- `finger_exercise02.py`: **Extracting the birth year from a date.** — Reads a birthday in `MM/DD/YYYY` format and extracts the year using string slicing.
- `finger_exercise03.py`: **Printing a repeated character with a `while` loop.** — Uses a `while` loop to concatenate and print the letter `x` a number of times based on the user's input, using `abs()` for the iteration count.
- `finger_exercise04.py`: **Finding the largest odd number among ten integers.** — Reads 10 integers and keeps track of the largest odd number entered without storing all inputs; prints a message if no odd number is entered.
- `finger_exercise05.py`: **Summing prime numbers below 1000.** — Computes the sum of all prime numbers greater than 2 and less than 1000 using nested `for` loops, a primality test, and `break`.
