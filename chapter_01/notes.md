# Chapter 1 — Getting Started

## Main ideas

- A computer executes instructions exactly as specified.

## Important concepts

- **Declarative knowledge**: Knowledge about facts. Describes **what is true**.

- **Imperative knowledge**: Knowledge about **how to** do something, usually expressed as a sequence of steps.

- **Algorithm**: A finite and precise sequence of instructions that, given some input, produces an output.

- **Computation**: The process of executing operations on data in order to produce a result.

- **Fixed-program computer**: A machine designed to solve a specific problem or perform a fixed set of tasks. Changing its program requires changing its circuitry.

- **Stored-program computer**: A machine that stores instructions in memory and can execute different programs without changing its hardware.

- **Interpreter**: A component that executes the legal instructions of a stored program.

- **Program counter**: Points to the location in memory of the instruction to be executed.

- **Flow of control**: The order in which instructions are executed, including changes in that order caused by tests and jumps.

- **Flowchart**: A graphical representation of flow of control. Rectangles represent processing steps, diamonds represent tests, and arrows indicate the order in which operations are performed.

- **Programming language**: A formal language used to express instructions that a computer can execute.

- **Universal Turing Machine**: A hypothetical computing machine with an unlimited tape and simple instructions for reading, writing, and moving along the tape, capable of simulating other Turing machines.

- **Church-Turing thesis**: States that if a function is computable, a Turing Machine can be programmed to compute it.

- **Halting problem**: The problem of determining whether an arbitrary program will continue running forever. Turing showed that no program can correctly determine this for every possible program.

- **Turing completeness**: A property of a programming language that means it can be used to simulate a Universal Turing Machine.

- **Literals**: Primitive constructs that directly represent values, such as numbers and strings.

- **Infix operators**: Operators written between their operands, such as `+` and `/`.

- **Syntax**: Defines which strings of characters and symbols are well formed.

- **Static semantics**: Defines which syntactically valid strings have a meaning.

- **Semantics**: Associates a meaning with each syntactically correct string of symbols that has no static semantic errors.
