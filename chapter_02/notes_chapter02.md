# Chapter 2 — Introduction to Python

## Main Ideas

- Programs manipulate objects, and every object has a type that determines what operations can be performed on it.
- Variables are names bound to objects; assignment changes these bindings.
- Programs can follow straight-line execution, branch based on conditions, and repeat computations using loops.
- Strings and tuples are ordered sequences that support operations such as indexing and slicing.
- Iteration allows a program to repeat instructions while a condition holds or for each item in a sequence.

## Important Concepts

- **Low-level language:** A programming language whose instructions are close to the operations performed directly by the hardware.
- **High-level language:** A programming language that provides abstractions that are easier for humans to read and write than machine-level instructions.
- **Interpreted language:** A language whose programs are executed by an interpreter rather than translated entirely into machine code before execution.
- **Compiled language:** A language whose source code is translated into machine code, or another lower-level representation, before execution.
- **Source code:** The human-readable program written in a programming language.
- **Machine code:** Instructions represented in a form that a computer's processor can execute directly.
- **Object:** A value in a program together with its associated type.
- **Type:** A classification that determines how an object is represented and what operations can be performed on it.
- **Scalar object:** An object that is treated as having no accessible internal structure.
- **Non-scalar object:** An object that has an internal structure made of other objects or elements.
- **Literal:** A notation that directly represents a value in source code.
- **Operator:** A symbol or construct that specifies an operation to perform on one or more operands.
- **Expression:** A combination of objects, operators, and other expressions that evaluates to a value.
- **Value:** The result represented by an object or produced by evaluating an expression.
- **Variable:** A name used to refer to an object.
- **Binding:** The association between a variable name and an object.
- **Assignment:** A statement that creates or changes a binding between a variable and an object.
- **Straight-line program:** A program whose statements execute sequentially without branching or repetition.
- **Branching program:** A program that can follow different execution paths depending on conditions.
- **Conditional:** A construct that executes code depending on whether a Boolean expression is true or false.
- **Nested statement:** A statement placed inside another statement or control structure.
- **Compound expression:** An expression built by combining simpler expressions.
- **Computational complexity:** A way of describing the amount of computational work required by an algorithm.
- **Conditional expression:** An expression that chooses between values depending on a condition.
- **String:** An ordered sequence of characters.
- **Overloaded operator:** An operator whose behavior depends on the types of its operands.
- **Repetition operator:** An operator that repeats a sequence a specified number of times.
- **Type checking:** Determining whether objects and operations are compatible with their types.
- **Indexing:** Accessing a single element of a sequence by its position.
- **Slicing:** Accessing a portion of a sequence using a range of indices.
- **Type conversion (casting):** Creating a value of one type from a value of another type.
- **Iteration (looping):** Repeated execution of a sequence of instructions.
- **While loop:** A loop that continues executing while its condition remains true.
- **Break:** A statement that immediately terminates the innermost enclosing loop.
- **For loop:** A loop that iterates over the elements of a sequence or another iterable.
- **Tuple:** An ordered, immutable sequence of objects.
- **Range:** An object representing a sequence of integers, commonly used with `for` loops.
- **In operator:** An operator used to test membership in a sequence or other container.
